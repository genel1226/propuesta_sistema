# Archivos de ejemplo para las pruebas

Las pruebas de `tests/Feature/Import` usan archivos reales que **no se versionan** porque contienen datos de clientes.
Si no están, esas pruebas se marcan como *skipped* (no fallan).

Para correrlas, copia aquí:

| Archivo esperado                      | Origen                                                  |
|---------------------------------------|---------------------------------------------------------|
| `cliente_gantt_indisa.xlsx`           | Carta Gantt Clínica Indisa.xlsx                         |
| `cliente_equipos_ediser.xlsx`         | Equipos Ediser 2026.xlsx                                |
| `plantilla_abatidor.xlsx`             | Plantilla de importación de Activos ABATIDOR.xlsx       |
| `plantilla_tableros.xlsx`             | Plantilla de importación de Activos TABLEROS ELECTRICOS.xlsx |
